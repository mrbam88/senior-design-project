Multi-Agent Simulation of an Epidemic

ABSTRACT

Software will simulate physical agents running on the JADE agent platform.
Agents will represent humans in a community experiencing an epidemic. Behaviour
was designed graphically using the INGENIAS Development Kit (http://grasia.fdi.ucm.es/main/q=en/node/127),
modified and agent applications were added using NetBeans IDE.

REQUIREMENTS TO RUN:
- Project only tested for Windows XP/Vista/7
- JAVA 6.0 (JDK 1.6.0 ,JRE 1.6.0)(available at http://java.sun.com/)


- Apache Ant 1.6.5  (available at http://ant.apache.org/)



TO RUN PROJECT
- Go to directory ../EE9v0_1/dist/
- Double-Click EE9v0_1.jar
- Exit GUI window to close application

NetBeans IDE is optional to run/view/edit the source code.
- Single source package: /Package 
- Library .jar files: dist/lib
